# Gold 777 Mebel korxonasi — Dashboard

Mebel korxonasi rahbari uchun veb-dashboard (HTML + CSS + JavaScript, kutubxonasiz).

## Tarkibi

- Chap panel: Dashboard, Savdo, Buyurtmalar, Ishlab chiqarish, Ombor, Materiallar, Mijozlar, Yetkazib berish, Qarzdorlik, Xodimlar, Hisobotlar, Sozlamalar
- 6 ta asosiy ko'rsatkich (bugungi savdo, oylik savdo, sof foyda, kassa qoldig'i, qarzdorlik, faol buyurtmalar)
- Buyurtmalar holati, tugab borayotgan materiallar, kassa pul oqimi
- 30 kunlik savdo grafigi, oylar bo'yicha taqqoslash, kategoriyalar bo'yicha diagramma (sichqoncha bilan ustiga borilsa raqam chiqadi)
- Eng ko'p sotilgan va eng foydali mahsulotlar, qarzdor mijozlar, topshiriladigan buyurtmalar

## Ishga tushirish

```bash
node server.js
```

Brauzerda oching: http://localhost:5173

Yoki `index.html` faylini to'g'ridan-to'g'ri brauzerda oching.
